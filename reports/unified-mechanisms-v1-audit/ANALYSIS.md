# 非零退出回执：记录器修正后的独立复核

首批 [机制实验](../unified-mechanisms-v1/ANALYSIS.md) 的一个样本受到 Windows 用量文件替换失败影响。本批只给评测器增加本地文件替换重试，用同一份任务与日志同时复核原生 DSH / 完整版。Harness 产品代码、策略、阈值、模型和任务未改变。数据集哈希与首批一致。

本批是额外观测，**不覆盖首批结果，不把成功替换进首批成功率**。
